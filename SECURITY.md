# Безопасность

## Как сообщить об уязвимости

Через [Security Advisories](https://github.com/akalikbergenov/cyclop/security/advisories/new)
на GitHub — это приватный канал, issue заводить не нужно. Ответ придёт, когда придёт:
проект личный, дежурства по нему нет.

## Поверхность атаки

Её практически нет, и это осознанно.

Cyclop не открывает портов и не слушает сеть. Ни обновлений, ни телеметрии, ни
аналитики. Исходящих соединений три, все только по https, и все перечислены
здесь, потому что новое соединение — это отдельное решение владельца, а не
деталь реализации:

- **Обложка трека**, и только на запасном пути управления плеером: скачивается
  по адресу, который отдаёт Spotify. Основной путь не ходит и туда — обложка
  приходит от самой macOS вместе с остальными данными о треке.
- **Курсы валют** для вкладки «Валюта»: раз в час с `cdn.jsdelivr.net`
  (открытые данные [fawazahmed0/exchange-api](https://github.com/fawazahmed0/exchange-api)),
  при недоступности — с `latest.currency-api.pages.dev`. Запрос уходит только
  пока вкладка включена в настройках; выключенная вкладка останавливает и его.
  Ничего о пользователе в запросе нет — это скачивание одного и того же
  публичного файла с курсами.
- **Лимиты Claude** для вкладки «Лимиты ИИ»: `api.anthropic.com/api/oauth/usage`,
  тот же адрес, откуда берёт цифры команда `/usage` в самом Claude Code. Выключено,
  пока пользователь не нажмёт «Показать лимиты» во вкладке (или не включит
  пункт в настройках). После этого запрос уходит не чаще раза в две минуты и
  только пока вкладка на экране. Отправляется только токен входа Claude Code;
  ответ — проценты израсходованных лимитов и время их сброса.

Всё прочее происходит на одной машине между процессами, которые и так
принадлежат пользователю.

Снимок с айфона попадает на полку через универсальный буфер обмена, то есть
средствами самой macOS: передачу выполняет Continuity, она зашифрована и
подтверждена Apple ID, а Cyclop лишь читает то, что оказалось в буфере. Своего
канала связи с телефоном у него нет.

## Разрешения

Одно, и только по нажатию кнопки: доступ к Календарю на вкладке «Календарь».
Ни автоматизации, ни универсального доступа, ни записи экрана в обычном режиме
работы не требуется. Не открываешь календарь — приложение живёт вообще без
разрешений.

Автоматизация и универсальный доступ запрашиваются только запасным путём для
управления плеером, если основной перестанет работать.

Вкладка «Лимиты ИИ» с включёнными лимитами Claude читает из связки ключей
запись `Claude Code-credentials` — вход, который сохранил сам Claude Code.
Читает через `/usr/bin/security`, как это делает Claude Code, поэтому системного
запроса не появляется: согласием служит кнопка во вкладке, которая говорит, что
именно будет прочитано. Токен держится только в памяти, на диск не пишется и
никуда, кроме `api.anthropic.com`, не уходит; refresh-токен не используется —
истёкший вход обновляет сам Claude Code при следующем запуске. Выключение пункта
в настройках забывает токен сразу.

## Что Cyclop читает и где это лежит

**История буфера обмена** живёт только в памяти процесса и не пишется на диск.
Записи с типом `org.nspasteboard.ConcealedType`, которым менеджеры паролей
помечают свои копирования, в историю не попадают вовсе.

**Снимки экрана из буфера** сохраняются файлами в `~/Pictures/Cyclop` и не
удаляются автоматически никогда. Сохраняется всякий скопированный в буфер снимок,
а не только тот, что понадобился, — включая случайно снятое окно банка или
почты. Папка целиком принадлежит пользователю; чистит
её только он. Отключается пунктом меню-бара.

**Полка** хранит в настройках приложения пути к файлам, а не сами файлы.

**Заготовки** лежат в `~/Library/Application Support/Cyclop/snippets.json`
обычным текстом. Файл читается при каждом открытии вкладки и переписывается,
когда заготовку добавляют или удаляют из панели. Для адреса и телефона этого
достаточно; для того, что не должно лежать читаемым, есть менеджер паролей.

**Перевод** выполняется `Translation.framework` полностью офлайн: текст не
покидает машину.

**Логи Claude Code и Codex** (`~/.claude/projects` и `~/.codex/sessions`)
вкладка «Лимиты ИИ» читает, пока открыта, и берёт из них только счётчики токенов,
время и, у Codex, записанные им лимиты. Текст переписки не сохраняется и не
покидает машину; сама вкладка ничего на диск не пишет.
